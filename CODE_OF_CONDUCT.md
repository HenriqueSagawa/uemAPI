# Código de Conduta

Este projeto adota os princípios do
[Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
com as adaptações necessárias ao contexto da uemAPI.

## Nosso compromisso

Como participantes, contribuidores e mantenedores, nos comprometemos a tornar a
participação no projeto uma experiência livre de assédio para todas as pessoas,
independentemente de idade, aparência, deficiência, etnia, identidade ou expressão
de gênero, nível de experiência, nacionalidade, orientação sexual, religião ou
condição socioeconômica.

Também nos comprometemos a agir de forma respeitosa com as instituições e pessoas
citadas nos dados, evitando exposição desnecessária de informações pessoais.

## Comportamentos esperados

- Demonstrar empatia e respeito por outras pessoas.
- Aceitar críticas técnicas construtivas.
- Focar no que é melhor para o projeto e para a comunidade.
- Reconhecer erros, pedir desculpas e aprender com a experiência.
- Preservar a privacidade e a segurança de terceiros.
- Basear discussões sobre dados em fontes e evidências verificáveis.

## Comportamentos inaceitáveis

- Assédio, intimidação, ameaças ou ataques pessoais.
- Comentários ofensivos relacionados a características pessoais ou identidade.
- Atenção sexual indesejada.
- Publicação de informações privadas de terceiros sem autorização.
- Exposição de credenciais, tokens ou dados pessoais em issues, pull requests ou
  logs.
- Uso do projeto para assediar pessoas ou instituições.
- Desrespeito reiterado às regras de revisão e proveniência de dados.

## Escopo

Este Código se aplica aos espaços do projeto, incluindo issues, pull requests,
discussões, revisões de código, documentação e outros canais oficiais. Também se
aplica quando alguém representa o projeto em espaços públicos.

## Aplicação

Relatos de conduta inadequada devem ser enviados de forma privada para o
mantenedor:

- **Responsável:** HenriqueSagawa (`@HenriqueSagawa` no GitHub)
- **E-mail:** henriquetutomusagawa@gmail.com

Inclua, se possível, links, capturas de tela e uma descrição objetiva do ocorrido.
Relatos serão tratados com confidencialidade. Não há prazo garantido de resposta;
o projeto é mantido de forma voluntária.

Os mantenedores podem remover, editar ou rejeitar comentários, commits, issues e
pull requests que violem este Código, e podem restringir temporariamente ou
permanentemente a participação de quem o descumprir. Medidas serão proporcionais
ao impacto e à recorrência do comportamento.
